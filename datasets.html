Dataset card

What a dataset entry documents.

Every dataset entry answers the following. The name in code is the key used in the registry data and in the proposal form.

Coverage & time geography_time
Extent, spatial unit or raster resolution, coordinate reference system, period covered, observation dates, and update cadence.
Variables & schema variables_schema
Every field with its type, unit, allowed values, and missing-value convention.
Source & collection provenance
Original providers, collection method, sampling, and the rights attached to each source.
Processing processing
Cleaning, joining, aggregation, and derivation steps, with the code that performs them.
Validation & quality validation
Completeness, consistency checks, comparison with reference data, and known error rates.
Limitations limitations
Coverage gaps, biases, temporal mismatches, and uses the dataset does not support.
Licence, access & citation version license access links citation
Download or access route, format, version, licence, and citation.
