Three registries

Urban evidence with context.

Each registry lists public resources of one kind. A resource is a documented release, not a download link: it states where the data came from, how it was processed, what it covers, and where it should not be used.

Resource standard

What every resource documents.

Six fields are common to all three registries. Each registry adds fields specific to its kind.

Geography & time
Spatial extent, spatial unit or resolution, time span, and update cadence.
Provenance
Original sources, how they were obtained, and the rights attached to them.
Processing
Every step between the source and the released resource, with the code that performs it.
Licence & access
The licence of the release, any access conditions, and what may not be redistributed.
Validation
How the resource was checked, against what, and the results of those checks.
Limitations & citation
Known gaps, biases, and misuse risks, with a version and how to cite the resource.

Principles

Context before download.

Provenance is part of the dataA resource without its sources and processing history is not released.
Indicators are defined, not only computedEvery indicator states what it is meant to measure and how well it does so.
Methods run end to endA method is released with the inputs, environment, and example needed to reproduce it.
Limits are stated up frontCoverage gaps, biases, and inappropriate uses are documented where people will read them.
Release process

From observation to resource.

CollectRecord every source, its rights, and how it was obtained before any processing starts.
ProcessScript each step so the release can be regenerated from the sources.
ValidateCheck coverage, consistency, and agreement with reference data; keep the results.
Document & releaseFill the resource card, assign a version and licence, and add the entry to the registry.
Repository

Releases are tracked in the open.

Resource cards, processing code, and validation results live in the public repository. Proposals, data requests, and corrections are handled as issues.
