Reproducible workflows.

Code and methods that connect raw observations to defensible urban measures. A method enters this registry when it runs end to end from documented inputs to a checked output.

Method card

What a method entry documents.

In addition to the six common fields, every method entry answers the following.

Problem & intended users
The urban question the method answers and who is expected to run it.
Inputs & outputs
Required inputs with formats and sources, and the outputs produced with their schema.
Steps & dependencies
The pipeline in order, with software dependencies and their versions.
Installation & runtime
How to set up the environment, expected run time, and hardware requirements.
Example & test data
A worked example with small test data that reproduces a published result.
Validation
How outputs were checked, including comparison with alternative methods where they exist.
Maintenance status
Whether the method is maintained, who maintains it, and known open issues.
Artifacts & citation
Repository, release version, licence, and how to cite the method.
