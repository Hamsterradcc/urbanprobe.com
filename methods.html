Registry 03 / Methods

Reproducible workflows.

Code and methods that connect raw observations to defensible urban measures. A method enters this registry when it runs end to end from documented inputs to a checked output.

Resource standard

Six common fields plus the method-specific fields below. Every method is released with an example that reproduces a published result.

Method card

What a method entry documents.

Every method entry answers the following. The name in code is the key used in the registry data and in the proposal form.

Problem & intended users problem_users
The urban question the method answers and who is expected to run it.
Inputs & outputs inputs_outputs
Required inputs with formats and sources, and the outputs produced with their schema.
Data sources provenance
Data the method was developed and tested on, and the rights attached to it.
Steps & dependencies processing
The pipeline in order, with software dependencies and their versions.
Installation & runtime installation_runtime
How to set up the environment, expected run time, and hardware requirements.
Example & test data example
A worked example with small test data that reproduces a published result.
Tested geography geography_time
Places and periods where the method has been applied and checked.
Validation validation
How outputs were checked, including comparison with alternative methods where they exist.
Maintenance status maintenance
Whether the method is maintained, who maintains it, and known open issues.
Limitations limitations
Known gaps, biases, and misuse risks.
Licence, access & citation version license access links citation
Repository, release version, licence, and citation.
